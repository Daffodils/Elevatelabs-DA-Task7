# Sales Data Analysis with Python and SQLite

This project creates a small sales database, runs queries to get sales summaries, and visualizes the data with charts.

## What it does

- Creates a database (`sales_data.db`)
- Adds sample sales data
- Uses SQL in Python to find total quantities and revenue for each product
- Prints the sales summary
- Shows a bar chart for revenue by product
- Shows a pie chart for revenue share of each product

## Requirements

- Python 3
- pandas
- matplotlib

required packages with:
```bash  
pip install pandas matplotlib  
```
